# v0.1 ミニマル MVP スコープ定義

> **期限**: 2026-05-22（判断ゲート）
> **目的**: UI が動くか / Gemini が使えるかを確認する最小版

---

## 1. やること（必須機能）

| ID | 機能 | 受け入れ基準 |
|---|---|---|
| F2 | カメラ撮影 | スマホ Chrome でカメラ起動 → 連続撮影できる |
| F3 | 下書き保存 | 撮影した写真群が 1 つの商品として Supabase に保存される |
| F4 | 一覧表示 | 下書きカードがカードグリッドで一覧表示される |
| F6 | AI 推定 | Gemini が商品名・カテゴリ・状態を返す |
| F10 | 画像リサイズ | 正方形クロップ + 長辺サイズ選択（1024 / 1920 / オリジナル）が動く |

---

## 2. やらないこと（v1.0 以降）

| ID | 機能 | 理由 |
|---|---|---|
| F1 | Google 認証 | v0.1 は飯田 1 人運用のため不要 |
| F5 | 複数人リアルタイム同期 | 単独利用で UI 検証先行 |
| F7 | Google 検索 Grounding 相場検索 | UI 動作確認が優先 |
| F8 | オークタウン CSV 出力 | 既存 Claude Code スキルが担う |
| F9 | PWA 化 | ブラウザ URL アクセスで十分 |
| — | 撮影方向ガイド | Phase 2 機能 |
| — | 自動グルーピング AI | Phase 2 機能 |

---

## 3. 動作確認 OK の判定

5/22 判断ゲートで以下を提示:

1. **動く動作確認版そのもの**（実機操作）
2. **撤退ライン項目への結果**
   - Gemini 商品名推定の精度（サンプル 10 商品で何割当たったか）
   - 撮影 → AI 結果表示までの所要時間（30 秒以内か）
   - スマホ Chrome でのカメラ動作（問題なし / あり）
   - Supabase 無料枠での写真 100 枚保存テスト（OK / NG）
3. **Before/After 比較**
   - 手動入力 vs 撮影アプリの所要時間差

---

## 4. スコープ外の判断

以下が出てきたら **v1.0 以降に送る**:

- 「ついでにこれもやりたい」系（複数人同期、認証、CSV 等）
- 完璧主義（エッジケース対応、エラーハンドリング詳細化等）
- パフォーマンス最適化（動けば OK）
- デザインの作り込み（最低限の shadcn/ui 標準で十分）

---

## 5. 撤退ライン（事前合意）

> 社長見立て: 全項目について「大丈夫だと思う」（懸念低）

| トリガー | 撤退判断 | 対処 |
|---|---|---|
| Gemini 商品名推定 5 割未満 | 仕切り直し | プロンプト改善 / GPT-4V 併用 |
| iOS Safari でカメラ動作不可 | 部分撤退 | Chrome / Android 主軸運用 |
| Supabase 無料枠で 100 枚保存できない | 構成変更 | Drive 直保存に変更 |
| 30 秒以上の応答 | UX 不成立 | リサイズ強化 / Flash 切り替え |
| 1 週間で完成しない | スケジュール延長 | 5/22 に+1 週間追加 or 中止 |
